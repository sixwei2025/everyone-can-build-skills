# 开始之前｜带着一件事读这本书

第三步，用功能词搜，不用界面词搜。 搜“技能”“专家团”“定时”“工作空间”，不要搜 “上传按钮”“第三个标签页”——按钮会改名，功能不会。 第四步，找不到就先手动做一遍。 把整件事自己走完，记下你按了什么顺序、交出了什么。等你在界面上看到对应入口，就知道该往哪一步放。这比空等一个按钮有用。

**名字对不上时，按这张表换算：**

| 书里叫 | 你在不同软件界面上可能看到的名字 |
| --- | --- |
| **技能** | Skill、能力、插件、自定义助手 |
| **专家** | Agent、角色、智能体、助手 |
| **专家团** | 团队、协作组、多智能体（Multi-Agent） |
| **工作空间** | 项目、文件夹、工作区（Workspace） |
| **定时任务** | 自动化、计划任务、触发器（Schedule） |

最后一句：先弄清这一步要完成什么，再去找哪个按钮。 按钮会变，这件事不会变。
