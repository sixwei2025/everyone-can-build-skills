# 开发前 6 格需求卡模板

> 节选自《人人都能开发 Skill》第 4 章｜作者：**袁六伟 · 台州汇芯**

在打开编辑器或让 AI 写 `SKILL.md` 之前，先花 3 分钟把下面 6 个格子填完，就能避开 80% 的返工：

| 格子 | 核心问题 | 你的回答（大白话填写） |
| :--- | :--- | :--- |
| **1. 解决什么高频痛点** | 这件事一周至少干几次？最烦哪里总是返工？ | |
| **2. 什么时候启动** | 你会用哪几句大白话唤醒它？什么时候**不要**启动？ | |
| **3. 每次给它什么材料** | 录音、聊天记录、Excel、链接，还是几句零碎大白话？ | |
| **4. 要交出什么成品** | Markdown 文档、表格、公众号排版，还是直接发群的消息？ | |
| **5. 绝对不能犯的错（红线）** | 哪些事绝对不能瞎编？哪些敏感隐私不能外泄？ | |
| **6. 1~2 份优秀样板间** | 你过去亲手改到最满意的 1~2 份成品放在哪里？ | |
